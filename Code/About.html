About PedalGo

A simple bike-rental website made as a college project.

Who We Are

PedalGo is a small college project based on the idea of making bike rentals simple and easy. Users can view bikes, filter them by type and submit a booking form.

Our Aim

Our aim is to create a clean and beginner-friendly website using HTML, CSS and basic JavaScript. We focused on simple navigation, forms and responsive design.
